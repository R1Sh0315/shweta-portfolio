# Shweta Sabale Portfolio

## Run locally

```bash
npm run dev
```

The Vite development server is configured for Replit on port 5000. The production build can be checked with:

```bash
npm run build
```

## Content note

Portfolio content is organized in `src/data/portfolio.ts`. The brief referenced an existing resume PDF, but no PDF was included with the imported files. The Download resume actions currently explain how to add the real file at `public/resume.pdf` rather than linking to a fabricated document.
